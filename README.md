# Azure VM Deployment & Remote Access

## Objective

Create and organize cloud resources in Microsoft Azure, deploy a Windows 11 virtual machine, verify that the deployment is running successfully, and establish remote access using Remote Desktop Protocol (RDP).

## Tools & Environment

* Microsoft Azure
* Azure Virtual Machines
* Windows 11 Pro
* Remote Desktop Protocol (RDP)
* Remote Desktop Connection

## Steps Performed

1. Created an Azure resource group named **RG-Lab** to organize the lab resources.
2. Configured a Windows 11 virtual machine named **VM-Lab**.
3. Deployed the virtual machine and verified that the Azure deployment completed successfully.
4. Confirmed that **VM-Lab** was running in the Azure portal.
5. Opened Remote Desktop Connection and initiated an RDP session to the virtual machine.
6. Verified successful remote access by reaching the Windows desktop on the Azure VM.
